# 📖 About

**Generative AI Projects** is a curated collection of practical Generative AI applications built using modern AI frameworks, Large Language Models (LLMs), and state-of-the-art development tools.

The repository explores real-world implementations of AI-powered systems, including intelligent chatbots, AI agents, Retrieval-Augmented Generation (RAG), prompt engineering, multimodal AI, text generation, image generation, and workflow automation.

Designed as both a learning resource and a professional portfolio, this repository demonstrates modern GenAI development practices through hands-on projects.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/mohammedasad2518/Gen-Ai.git
```

Navigate into the repository

```bash
cd Gen-Ai
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run a project

```bash
python app.py
```

or

```bash
jupyter notebook
```
